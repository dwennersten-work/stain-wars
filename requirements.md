# Purpose
To have a way to run a live multi-user program that will show the usage of a virtual machine for students learning about cloud computing. 

# Platform
- Digital ocean droplet
- If possible, let's create this and upload it to github and then create an install script that I can run from my digital ocean vm that will install the game you created. 

# Audience
- Online Middle school and high school students
- No student accounts to log in
- Completely online with no downloads
- randomly assign fashion model or famous singer/actor names to students as they log in.  

# Gameplay
- It should be fast, engaging, and fun
- Students like First person shooter games and games that have progression elements. 
- Random idea - students fight each other and every time they "win" against another user they gain money to purchase "outfit" upgrades that they can select from a list of outfits. 
- The "weapons" are weapons of mass outfit destruction - mustard bottles that squirt, throwable "hamburger" grenades, etc.
- Each outfit upgrade increases it's "stain resistance" which makes them "stronger" 
- Shoot for derpy low-poly fun and wild colors for outfits.  The more wild colored the outfit, the stronger it is... so students can visually identify which other students are the "strongest".  Defeating students with stronger outfits earns more money. 
- students can join just by clicking on the link BUT if they exit and re-enter they start over (the goal here is to minimize unecessary features)

# Token Limit
- You need to complete the entire game in one 5 hour token limit using opus 5.5 on a pro plan (we can build on this in phases, so create a to-do and mark things off of the to-do as you go) 
- You need to build a working version in like 30 minutes... something that can be built on top of later, but just get the "gist" for now.  Still needs to be "complete" and "fun" and meet the above gameplay requirements, but try to to include too many extra features or error checking. 

# Admin console 
- There should be some sort of admin console that allows the teacher to screenshare during game play that shows system usage - or we could just have a simple script running that will display the usage.
